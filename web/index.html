Como usar

Amplie os grupos para separar os ativos. Para recortar a carteira, escolha Área, marque pelo menos três pontos e conclua. Arraste os vértices para ajustar.

Com o mapa em foco: Espaço marca o centro, Enter conclui, Backspace desfaz e Escape cancela. Nos vértices, use as setas para ajustar; Shift aumenta o deslocamento.
